@stencil/store + globalScript repro

The component below renders state.label and state.clicks from a @stencil/store store created at module scope. The globalScript imports that store — the label reading ready proves the globalScript ran.

Expected

Every click on "Increment store counter" writes state.clicks + 1 to the store and the component above re-renders immediately. That's what happens on @stencil/core 4.32.0 and older (npm i -D @stencil/core@4.32.0 && npm run build to check).

This branch

This is the works-on-4.32 branch: the same code with @stencil/core pinned to 4.32.0, the last version where this works. The counter should update on every click. Switch to master (pinned to 4.43.5) to see the bug: the counter stays at 0 there until you force an unrelated re-render with the second button.
